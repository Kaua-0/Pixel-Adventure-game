# 🎮 Pixel Adventure

Um jogo de plataforma 2D no estilo retrô desenvolvido para web. O objetivo é navegar pelas fases, coletar moedas, desviar de obstáculos e alcançar a bandeira para completar o nível!

## 🚀 Funcionalidades

- **HUD Dinâmico:** Acompanhamento em tempo real de moedas coletadas, vidas restantes e fase atual.
- **Suporte Mobile:** Interface responsiva com botões virtuais para jogar em dispositivos móveis.
- **Leve e Rápido:** Renderização direta em HTML5 Canvas sem dependências de bibliotecas externas.
- **Mecânicas Clássicas de Plataforma:** Movimentação, pulo, coleta de itens e sistema de vidas.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura da página e elemento `<canvas>`.
- **CSS3:** Estilização da interface, HUD e botões mobile.
- **JavaScript (ES6+):** Lógica do jogo, movimentação, colisões e controle de estados.
